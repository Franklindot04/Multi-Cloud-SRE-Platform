# Scripts

Small helper scripts used by the Makefile, CI and local development. Shell scripts are linted with `scripts/shellcheck.sh`, which runs `shellcheck -S style` (the strictest level, so info and style findings fail) at the version CI installs (0.11.0); `make argocd-check` and `make apps-lint` both use it. Scripts must be idempotent, use `set -euo pipefail`, print usage with `-h`, and avoid embedding credentials.

- `teardown-prep.sh --context CONTEXT [--region R] [--cluster-name N] [--dry-run]`: prepares a cluster for `terraform destroy` (removes the Argo CD cluster Secret labels, then deletes the CloudNativePG `Database` objects and `Cluster`, the `RabbitmqCluster` and the claims, and checks volumes, load balancers and security groups; 12 steps, listed in the script header and the runbook). When an operator is already gone, it removes the one operator finalizer from a stuck `Database` or `RabbitmqCluster` and says so; any other finalizer is left alone and the script stops. See the [data layer runbook](../docs/runbooks/data-layer.md#teardown) and its note on a namespace stuck in `Terminating`. Tested against a fake `kubectl` and `aws` in `scripts/tests/fakes` by `scripts/test-scripts.sh`.
- `chart-contract-check.py` and `python-with-yaml.sh`: contract checks run by `data-manifests-check.sh`, `deploy-check.sh` and `argocd-check.sh` (no hook-only chart, no Helm-hook Job that creates Secrets, the PostgreSQL PreSync gate, the sync-wave order of the data ApplicationSets).
- `verify-image.sh SERVICE|all [DIGEST]`: checks the signature, the SBOM attestation and the build provenance of a published image with cosign, pinned to the images workflow on `main` of this repository and the GitHub OIDC issuer; prints PASS or FAIL per check and per image and exits non-zero on any failure. See [verify an image](../docs/runbooks/service-deployment.md#verify-an-image). Tested against a fake `cosign` in `scripts/tests/fakes`; it has not yet run against real signatures.
- `check-trivyignore.sh [FILE]`: checks `.trivyignore` before an image scan: every entry needs a `# reason:` line directly above it and an unexpired `exp:YYYY-MM-DD` date. Run by the images workflow and tested by `scripts/test-scripts.sh`.
